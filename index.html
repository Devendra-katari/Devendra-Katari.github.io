Smart Voting System

A Flask web app that gates voting behind two factors: a Voter ID + password, then a live face-verification check against the photo captured at registration. Built as team leader for a final-year project — I designed the registration → face-capture → verification → voting pipeline, and an SQLite schema to log every registration, login attempt, and vote for traceability. CASE FILE · 02

Employee Attrition Prediction

A logistic regression model predicting which employees are likely to leave, trained on the IBM HR Analytics dataset (1,470 employees, 35 features). Only ~16% of employees in the data actually left, so the evaluation leans on precision, recall, and ROC-AUC rather than raw accuracy — and the notebook compares a few decision thresholds since the default 0.5 cutoff under-catches true leavers. Odds ratios pulled out overtime, frequent travel, and low job satisfaction as the strongest risk factors, and tenure and stock options as the strongest protective ones.
